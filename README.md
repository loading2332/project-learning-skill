# project-learning-skill

一个用于辅助学习项目的 Skill。

让 AI 在阅读当前仓库源码、文档和已有学习记录后，生成结构化的项目学习内容，例如课程、QA、语法笔记、完成度检查和阶段复盘。

## 功能定位

`project-learning-skill` 适合用于以下场景：

- 学习一个已有代码项目
- 根据项目源码生成逐节教程
- 针对某一课补充 QA 答案
- 整理语法点笔记
- 检查某一课是否完成
- 每隔几课生成阶段复盘
- 保持学习文件结构统一

## 何时触发

提出类似请求时，可以触发该 Skill：

```txt
生成下一课内容
生成第 N 课内容
完成 QA
完成 syntax
